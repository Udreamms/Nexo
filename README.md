# Nexo Salud

Maquetas y sitio web de Nexo, plataforma para comparar y cotizar planes de Isapre.

- `web-nexo/`: sitio público (inicio, cotiza, revisa, guía, aprende, para agentes).
- `web-nexo-pro/`: maqueta de la herramienta para agentes (Nexo Pro).
- `Nexo - Maqueta de plataforma v*.html`: versiones de la maqueta de plataforma.
- `fotos/`: imágenes usadas en el sitio.
- `capturas/`: capturas de pantalla en escritorio y celular.
- `landing2.py`: script de la landing.
